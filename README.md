# Equity Research AI Agent

> **SEBI Educational Disclaimer:** This project and all outputs generated by it are strictly for financial education, quantitative research, and public-filing data synthesis under **SEBI (Research Analysts) Regulations, 2014** and **SEBI (Investment Advisers) Regulations, 2013** principles. It does **not** constitute registered investment advice, portfolio management, or a recommendation to buy, sell, or hold any security.

An autonomous, institutional-grade **Equity Research AI Agent** built for complete **fundamental analysis**, **Indian stock analysis**, and **Nifty 50 / NSE & BSE equity research**, powered by **PyKX / KDB-X** columnar processing, deterministic **6-layer quantitative scoring**, **Reverse-DCF / 5-Year FCFF DCF & IRR/MOIC returns modeling**, **PyMuPDF forensic annual report auditing**, and **interactive Chart.js HTML dashboards + structured Markdown memos**.

Whether you are an individual investor learning **how to do stock research** step by step, a quant researcher automating **Nifty stock analysis**, or a developer connecting Claude Code, ChatGPT/Codex, Cursor, or Antigravity via MCP, this agent standardizes institutional equity diligence using 100% verified, public exchange data.

## Key Capabilities

1. **Investor Goal Intake & Strategy Weighting (Stage 0)**
   - Maps return expectations (`2x_3x`, `3x_5x`, `5x_10x_plus`), drawdown tolerance, horizon, market (`IN`, `CA`, `US`, `GLOBAL`), and cap-focus onto 6 quantitative archetypes (`balanced_institutional`, `compounder_growth`, `deep_value`, `policy_capex`, `conservative_income`, `multibagger_hunter`).
2. **KDB-X / PyKX High-Speed Columnar Screening (Stage 1)**
   - Caches financial statements and market histories as native `.kdb` columnar tables (`kx.serialize` / `kx.deserialize`), computing cross-sectional percentile ranks and Z-scores across sectors.
   - Scores every equity on a transparent 100-point framework spanning:
     1. Balance Sheet & Cash Conversion (`CFO/EBITDA`, `FCF/PAT`, Net Debt/EBITDA, Interest Coverage)
     2. Business Quality & Capital Efficiency (`ROIC`, `Incremental ROIC`, `ROIC–WACC` spread, Sales/PAT CAGR)
     3. Valuation & Margin of Safety (`EV/NOPAT`, `FCF Yield`, Reverse-DCF implied growth)
     4. Governance, Audit & Litigation
     5. Macro, Geopolitical & External Risk
     6. Market Scale & Trading Liquidity (`ADTV`)
3. **Forensic Annual Report & Risk Auditor (Stage 2)**
   - Parses uploaded **Annual Reports** and **Independent Auditor's Reports (PDF)** using `pymupdf` (`fitz`) with page-level citations for Adverse/Going-Concern opinions, CARO/ICFR flags, contingent liabilities, consortium bank loans, pledge risks, RPTs, and government contract dependencies.
4. **Standardized Institutional Research Report & Interactive Web Dashboard (Stage 3)**
   Generates both `<SYMBOL>_memo.md` and `<SYMBOL>_dashboard.html` covering 8 cohesive sections:
   - **Section 0 — Introduction:** Company profile, multi-year scale trajectory, Annual Report outlook, capex & order-book briefing with investor impact & clickable source pills.
   - **Section 1 — Executive Summary:** Composite quality verdict, AI/disclosure briefing of material events, and integrated forensic audit & solvency summary.
   - **Section 2 — Price Trend, 5Y Returns Analysis & Valuation Bands:** 52W/50-DMA/200-DMA chart, 5-year **IRR / MOIC Returns Scenario Model & Value Attribution** (EBITDA growth vs multiple shift vs cash/dividends) + 2-way sensitivity matrix, and 5-year monthly **Trailing P/E Bands (±1 SD)**.
   - **Section 3 — Latest Earnings Highlights (Before Financials):** 4-quarter EPS **Beat/Miss Surprise %**, 30-day forward EPS revisions, YoY/QoQ variance table, and source-attributed concall/earnings release briefings.
   - **Section 4 — Multi-Year Financial Track Record & Segment Mix:** 4Y Annual & 4Q Quarterly tables + conditional **NSE Ind-AS 108 XBRL Operating Segment Breakdown** (revenue mix, EBIT margin, QoQ/YoY momentum, annualized segment ROCE).
   - **Section 5 — Intrinsic Cash-Flow Valuation (DCF) & Equity Bridge:** 5-year Unlevered FCFF projection, WACC × Terminal Growth sensitivity grid, and EV/EBITDA SOTP check.
   - **Section 6 — Ownership Flow, Consensus & Competitive Moat Matrix:** Screener.in FII/DII/Promoter shareholding trends, NSE Form C insider disclosures, external analyst consensus, multi-horizon relative performance vs Nifty 50 / S&P 500 / TSX, plus a **2×2 Competitive Positioning Matrix** and **4-Pillar Structural Moat Scorecard**.
   - **Section 7 — Analytical Conclusion, Rating Framework & Data Provenance:** Plain-English key analytical drivers, composite Grade (`A+`..`D` / Stars), transparent 6-pillar scoring reconciliation table, 5-tier Rating Scale Guide, live **Data Sources & Strict Actual-Data Verification**, and **SEBI Disclaimer**.
5. **Model Context Protocol (MCP) Server**
   - Exposes all tools over standard JSON-RPC 2.0 stdio (`mcp_server.py`) for integration with external AI clients.

## How to Do Systematic Stock Research & Fundamental Analysis (Step-by-Step)

To help investors and AI agents perform structured **fundamental analysis** on **Indian stocks**, **Nifty 50 constituents**, or global equities without guesswork, the workflow executes a disciplined 4-stage pipeline:

1. **Define Investment Goals Before Screening (`goal-intake`):** Match your horizon (`3–10+` years), drawdown tolerance, and market-cap preference (`large` Nifty 50 leaders vs `small_mid` compounders) to an explicit strategy weight profile.
2. **Screen Cash Flows & Capital Efficiency First (`idea-generation`):** During **Indian stock analysis**, verify operating cash conversion (`CFO/EBITDA`), free cash flow (`FCF/PAT`), solvency (`Net Debt/EBITDA`, interest coverage), and capital allocation (`ROIC vs WACC` spread) rather than chasing trailing P/E headlines.
3. **Inspect Quarterly Momentum & Operating Segments (`earnings-india` & `three-statement-india`):** Track 4-quarter EPS beat/miss surprises, 30-day estimate revisions, margin progression (`bps`), and statutory **NSE Ind-AS 108 XBRL segment disclosures** before reading trailing financial summaries.
4. **Cross-Check Intrinsic Value, Moat & Audit Risk (`dcf-india`, `comps-india`, `audit-qc-india`):** Compare Current Market Price against 5-year Unlevered FCFF DCF, Reverse-DCF implied expectations, 5-year IRR/MOIC sensitivity, peer ROIC comparison tables, and Annual Report forensic checks (auditor qualifications, contingent liabilities, promoter pledges, and related-party transactions).

## Strict Actual-Data Policy

This agent strictly enforces an **Actual Data Only** invariant across ingestion, quantitative scoring, valuation modeling, and UI/Markdown rendering:

- **Zero Synthetic / Mock Fallbacks:** Missing statements, unavailable XBRL segments, or unpopulated ratios are never fabricated or filled with placeholder values. Unavailable cells render transparently as `—`, and dependent models omit themselves cleanly with explicit reasons.
- **Ingestion Guardrail (`data_ingestor.py`):** Every fetched bundle runs `_actual_data_checks(...)`; nonexistent or hollow symbols with no verified quote or financial statements raise a strict error instead of producing phantom scores.
- **No Unfounded Balance-Sheet Zeroing (`scoring_engine.py`):** Missing debt/cash lines default to `NaN` (not `0.0`) unless an actual balance sheet exists, and Reverse-DCF scoring refuses to assume arbitrary historical growth rates when multi-year CAGR is absent.
- **Strict DCF & Returns Gating (`standardized_report.py`):** 5Y FCFF DCF and 5Y IRR/MOIC scenarios execute **only** when verified revenue, positive trailing EBIT/EBITDA, shares outstanding, CMP, and observed CAGR exist; FCF conversion uses actual model/statement output with zero magic fallback multipliers.
- **Zero Look-Ahead EPS Imputation:** 5-year trailing P/E bands map historical closing prices strictly against matching or previously reported fiscal EPS — never backfilling future fiscal-year EPS onto earlier periods.
- **Per-Report Provenance Audit:** Every Markdown memo and HTML dashboard embeds a **Data Sources & Verification Status** table reporting exactly which feeds were `Verified`, `Unavailable`, `Skipped`, or `Attached & Audited`.

## Installation & Quick Start

### 1. Install Dependencies
```bash
pip install -r requirements.txt
```

Optional environment variables:
- `OPENAI_API_KEY`: Enables OpenAI LLM function-calling and disclosure synthesis (omit or pass `--offline` to run 100% deterministically with zero LLM dependency).
- `KDB_HOST` & `KDB_PORT`: Optional remote licensed KDB-X / `q` IPC server (defaults to embedded PyKX binary `.kdb` mode automatically).

### 2. Generate a Single-Stock Institutional Dashboard & Memo
```bash
python cli.py dashboard RELIANCE.NS --open
```
Or attach an Annual Report / Independent Auditor's Report PDF for page-cited forensic analysis:
```bash
python cli.py dashboard BEL.NS --pdf path/to/AnnualReport.pdf --open
```

> **Sample Dashboard Output:** View [`exampledashboard.html`](exampledashboard.html) (generated from actual live market & filing data for **TCS.NS**) for an example of the full 8-section interactive HTML output.

### 3. Run the Autonomous Multi-Step Research Agent
```bash
python cli.py run "Find Indian defense or IT compounders, inspect BEL.NS for govt contract risk, and save memo" --offline --open
```

### 4. Interactive Investor Session (Stage 0 -> Stage 3)
```bash
python cli.py chat --offline
```

### 5. Launch as an MCP Server (JSON-RPC 2.0 Stdio)
```bash
python mcp_server.py
```

### 6. Run Verification Test Suite
```bash
python -m pytest test_agent.py -v
```
